# Smart Pick
### Smart Pick is a client-side quality-of-life mod created to add more functionality to the pick block function by not just giving the matching block but also checking for similar blocks or items related to the block you picked.
## For Example:
- Picking stone will give cobblestone if no stone is present in the inventory and vice versa
- Picking deepslate will give cobbled deepslate if no deepslate is present in the inventory and vice versa
- Picking grass will give dirt if no grass is present in the inventory and vice versa
